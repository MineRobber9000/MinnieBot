# MinnieBot

A Discord bot that runs MiniScript code.

## Requirements

- CMake
- C/C++ compiler
- `discord.py`

## Setup Instructions

- Use CMake to build MiniScript (the version here is a hacked up Command Line 1.3).
- Copy the `miniscript` binary into the `bot` directory.
- In the `bot` directory, copy `config.py.skel` to `config.py` and put the bot token in the `token` variable.
- Run `bot.py`.
